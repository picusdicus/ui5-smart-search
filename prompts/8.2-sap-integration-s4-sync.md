Functions:

getLastSyncTime(entityName)
  SELECT lastSyncTime FROM "smart_search_SyncLog"
  WHERE entity = entityName
  Return Date or null if not found

updateSyncLog(entityName, count)
  UPSERT "smart_search_SyncLog"
  SET lastSyncTime = NOW(), recordsSynced = count
  WHERE entity = entityName

fullSync()
  1. fetchBusinessPartners(500) from s4-client
  2. For each BP:
     - skip if isBlocked = true
     - text = "${name} ${language}"
     - vector = await embedText(text)
     - UPSERT "smart_search_Customers"
       (ID, name, embedding)
       VALUES (bp.id, bp.name, serialize(vector))
     - log progress every 20 records
  3. updateSyncLog('Customers', count)
  4. Return { synced: count, errors: errorCount }

deltaSync()
  1. lastSync = await getLastSyncTime('Customers')
  2. If no lastSync → run fullSync() instead
  3. fetchBusinessPartners(500)
  4. Filter: bp.lastChanged > lastSync
  5. Same embed + upsert as fullSync
  6. updateSyncLog('Customers', count)
  7. Return { synced: count }

All functions use getConnection() from hana-vector.js.
Log with prefix [s4-sync].
