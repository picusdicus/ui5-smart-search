Add a "New Customer" feature to the smart-search app.

The feature allows users to:
1. Click a "New Customer" button on the search page
2. Describe what kind of BP they want to create
3. Get AI-suggested form fields based on a similar 
   existing BP from our vector index
4. Review and edit the suggestions
5. Confirm to create the BP in API Hub

Backend:
- Add createCustomer action to search-service.cds
- Implement handler in search-service.js using
  createBusinessPartner from s4-client.js
- After creation sync new BP to vector index

Frontend:
- Use existing suggestCustomer action already 
  implemented in search-service.js
- Follow existing UI patterns in the app
- Handle busy states, errors and success messages

Use the existing code patterns, agents and skills
already established in this project.
